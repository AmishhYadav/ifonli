# src/server/domain

Pure, dependency-free commerce rules (plan 7.1-7.12). No DB, no env, no `server-only`; time is a `now: Date`
argument and randomness is injectable. All money is **integer paise**. Import from `@/server/domain`.

| Module                  | Contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tax.ts`                | `taxIncludedIn(gross, rateBp)`: GST is inclusive; `taxable = round-half-up(gross*10000/(10000+rate))` (BigInt), `tax = gross - taxable`. `splitGst(tax, {seller, buyer})`: same state -> `cgst = floor(tax/2)`, `sgst = tax - cgst` (odd paisa to SGST); else all IGST.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `pricing.ts`            | `priceCart(input)`: one deterministic function for cart, checkout and order creation. Discount is allocated pro-rata across coupon-eligible lines (floor each; leftover paise to the largest eligible line, first on ties, spilling to the next largest only if that line has no room). Shipping = zone override ?? flat, free when `subtotal - discount >= threshold`, or via a `free_shipping` coupon (`shippingDiscountPaise`). COD fee only for `cod`. Shipping/COD fee tax uses the dominant line rate (largest sum of post-discount line totals, ties to the higher rate) or a fixed rate. `gst` = sum of `splitGst` over every taxed item (each line, shipping, COD fee), so `cgst+sgst+igst === taxIncludedPaise`. `savingsVsMrpPaise` = sum((mrp - unit) * qty), excluding coupons. Invalid input throws `PricingError`. |
| `coupons.ts`            | `validateCoupon(record, ctx)` returns `{ok:true, applied}` or `{ok:false, code, message}`. Check order: inactive, not_started, expired, usage_exhausted, per_customer_exhausted, no_eligible_items, min_subtotal, stacking. Min subtotal compares the **whole cart** subtotal. Percent = floor(eligible*bp/10000), capped by max; fixed = min(value, eligible). Dates are shown in IST. `startsAt`/`endsAt` are inclusive.                                                                                                                                                                                                                                                                                                                                                                                                        |
| `availability.ts`       | `availableQty` = onHand minus active, unexpired (`expiresAt > now`) reservations, floored at 0. `clampQty` caps at `min(available, maxPerLine)`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `shipping.ts`           | `codEligibility` (setting, pincode, excluded items, `total <= max`) with human reasons. `deliveryEstimate` counts working days (processing + zone transit), skipping Sundays; never lands on a Sunday; returns IST `YYYY-MM-DD` strings.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `order-state.ts`        | Three axes (`status`, `payment`, `fulfillment`) with table-driven maps, `canTransition`/`assertTransition` (`OrderTransitionError`), `customerStatusLabel`, `isCustomerCancellable`, `refundableAmount`. Terminal: completed, cancelled, refunded, returned. Only exception: `expired -> confirmed` (late capture, plan 7.6).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `ids.ts`                | `generateOrderRef` -> `IFO-YYMM-XXXX` (IST month, Crockford base32 minus I/L/O/U). `financialYear` (1 Apr-31 Mar, IST). `formatInvoiceNumber(seq, now)` -> `IFO/26-27/000123` (16 chars, GST limit; seq 1..999999).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `tokens.ts`             | `createAccessToken()` (32 random bytes base64url + sha256 hex), `verifyAccessToken` (constant-time, never throws).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `razorpay-signature.ts` | `verifyPaymentSignature` (HMAC over `orderId                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | paymentId`with the **key secret**),`verifyWebhookSignature`(HMAC over the raw body with the **webhook secret**); both constant-time and return false on bad input.`assertAmountMatches` requires equal safe-integer paise. |
| `ist.ts`                | Asia/Kolkata helpers (fixed +05:30 offset, no DST): `istParts`, `formatIstDate`, `istDateString`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
